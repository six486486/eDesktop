# eDesktop

eDesktop 是一款面向 Windows 10/11 的桌面整理与效率工具。它可以把常用应用、文件、文件夹和 Windows 系统桌面项整理到多个收纳盒中，同时提供便签、待办列表、番茄钟和配置快照，让桌面保持整洁又不失实用性。

当前仓库仅发布 Windows x64 便携版，不包含源代码和安装包。

## 主要功能

- **桌面收纳盒**：按游戏、学习、工作等用途建立多个收纳盒，支持拖动、缩放和同类组件动态层级。
- **原生文件操作习惯**：图标单击选中、双击打开、右键显示菜单，可拖动调整顺序或移动到其他收纳盒。
- **Windows 系统桌面项**：支持收纳“此电脑”“回收站”“网络”“控制面板”和“用户文件”等标准桌面项。
- **待办列表**：提供“我的一天”和“临时安排”，支持编辑、排序和跨分组拖动；“我的一天”任务可每日刷新完成状态。
- **番茄钟**：提供专注与休息模式，帮助建立工作节奏。
- **桌面便签**：快速记录临时想法和重要事项。
- **快照与恢复**：保存组件配置、内容、位置和多显示器布局，并可手动导入、导出和恢复。
- **多屏适配**：支持扩展屏、负坐标和不同 DPI 缩放比例，组件可以在多块显示器之间移动。
- **开机启动与托盘运行**：可在控制中心开启开机自动运行，通过系统托盘打开控制中心或退出软件。

## 适用范围

eDesktop 适合：

- 桌面快捷方式、文件和文件夹较多，希望按用途分类整理的用户；
- 需要便签、待办和专注计时常驻桌面的学习者、研究人员和办公用户；
- 使用双屏或多屏，希望组件位置能适应不同显示器布局的用户；
- 希望使用免安装、解压即用软件的 Windows 用户。

当前版本仅支持 **Windows 10/11 x64**，不支持 macOS、Linux、Windows ARM 和 32 位 Windows。

## 下载与使用

1. 打开本仓库右侧的 **Releases** 页面。
2. 下载最新的 `eDesktop-<版本号>-win-x64-portable.zip`。
3. 将 ZIP **完整解压**到一个普通文件夹，例如 `D:\Apps\eDesktop`。
4. 双击解压目录中的 `eDesktop.exe`。
5. 通过 Windows 右下角托盘中的 eDesktop 图标打开控制中心，然后添加或管理组件。

请勿只复制 `eDesktop.exe`。同目录中的 `resources`、DLL 和其他运行库都是应用正常运行所必需的。

如果启用了“开机自动启动”，请先把便携版放到准备长期使用的位置，再开启该选项。之后移动或重命名应用文件夹会导致原启动路径失效，需要重新关闭并开启“开机自动启动”。

## 收纳盒的重要说明

把普通文件或文件夹拖入收纳盒后，eDesktop 会将真实项目移动到：

```text
%USERPROFILE%\Documents\eDesktop\收纳文件
```

这不是图标的虚拟分组。请不要在应用运行期间手动删除或移动该目录中的内容。正常退出 eDesktop 时，软件会把收纳项目归还到原路径，并恢复桌面图标位置；如原位置不可写，会回退到当前用户桌面且不会覆盖同名文件。

建议通过托盘菜单或控制中心正常退出软件。应用也带有异常退出恢复机制，但断电、系统崩溃、磁盘故障等情况仍应依靠您自己的文件备份。

## 快照不等于文件备份

eDesktop 的快照用于保存：

- 组件种类、标题、内容、位置和尺寸；
- 收纳盒的项目引用和排列；
- 多显示器布局与部分应用设置。

快照**不会复制文件本体**，不能代替 OneDrive、文件历史记录、NAS 或其他备份方案。恢复快照时，已经被用户删除或移动且无法找到的文件不会凭空恢复。

## 本地数据与隐私

eDesktop 的组件配置和快照保存在本机：

```text
配置：%APPDATA%\eDesktop\desktop-workspace.json
快照：%APPDATA%\eDesktop\workspace-snapshots
收纳文件：%USERPROFILE%\Documents\eDesktop\收纳文件
```

软件的核心桌面整理功能无需登录账号，也不会主动把收纳文件上传到云端。

## 常见问题

### Windows 提示“未知发布者”怎么办？

当前便携版尚未进行商业代码签名，因此 Windows SmartScreen 可能显示安全提示。请只从本仓库的 Releases 页面下载，并核对 Release 页面提供的 SHA-256。

### 解压后可以移动应用文件夹吗？

没有开启“开机自动启动”时可以移动；开启后再移动会使启动路径变化，需要重新设置开机启动。建议一开始就解压到固定目录。

### 升级版本会清空组件吗？

不会。配置和收纳数据位于用户目录，不在便携版程序目录中。退出旧版本后，将新版解压到固定目录再运行即可。升级前仍建议创建一次配置快照，并对重要文件进行常规备份。

### 如何彻底退出？

在 Windows 系统托盘中找到 eDesktop 图标，右键后选择退出。关闭控制中心窗口不一定代表程序已经退出。
