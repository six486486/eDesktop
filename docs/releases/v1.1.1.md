这次给小栖加了一个聊天偏好窗口。想让它怎么称呼你、回复长一点还是短一点、要不要接着追问，现在都能自己改。

点聊天窗口的小铃铛，进入 **聊天偏好**，修改后点“保存偏好”，下一条回复就会用上。这个窗口不用启动 Ollama 也能设置。

直接说也可以，比如“以后叫我小李，回答短一点，不要追问我”。聊天和设置窗口改的是同一份偏好，以最后一次明确修改为准；“这次详细一点”只影响这一轮。旧对话的后台记忆整理不会把刚改好的设置覆盖回去。

另外补上了 README 的入口说明和界面截图，也把小栖现在怎么识别意图、为什么继续用 JSON 存记忆、暂时用不上多步执行这些选择写清楚了。没有新增模型服务或数据库依赖。

下载 `eDesktop-1.1.1-windows-x64.zip`，完整解压后运行里面的 `eDesktop.exe`，请保留整个程序文件夹。支持 Windows 10/11 x64。

从旧版更新前，先从托盘正常退出，替换程序文件时 **保留自己的 `data` 文件夹**，里面有设置、待办、聊天和离线语音模型。便携包不包含个人数据，附带 `.sha256` 校验文件。
