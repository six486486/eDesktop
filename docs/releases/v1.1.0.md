这次更新的主角是小栖，一只待在桌面上的小猫。

我想让它帮上几件日常小事：早上报个天气，快到点时提醒一下，手上正忙的时候听你说一句。原来的待办和番茄钟都还能直接用，小栖的操作也会落在这些组件里，方便随时查看和修改。

这版可以试试：

- 点聊天窗口的小铃铛，设置天气城市、播报时间和提醒声音；之后也能直接说“天气改成九点播报”。
- “我的一天”按开始时间提醒；说“二十分钟后提醒我取快递”，会在“临时安排”里记下一条真实待办。接着说“改成半小时吧”，就能修改刚才的提醒。
- 按 **Ctrl+Alt+V** 开始说话，再按一次结束并自动发送。聊天框保持收起，小栖竖耳听，回复出现在气泡里；按 Esc 或点 × 可以取消。
- 说“陪我专注一刻钟”启动番茄钟。专注和休息结束时都有气泡和短短的喵声，声音可以关闭。
- 明确告诉它“以后写代码45分钟，看书25分钟”，下次就能沿用。小铃铛里的“**小栖记住的事**”能查看习惯、最近操作和原话，也能逐条忘记。“这次20分钟”只影响这一次。

小栖的自然语言理解使用本机 Ollama，执行层会检查工具权限、参数来源和当前状态，成功保存后才给回执。新消息可以打断旧回复，迟到结果不能再修改新状态。这部分实现和测试也一起放进了源码，感兴趣可以看看[桌宠文档](https://github.com/six486486/eDesktop/blob/v1.1.0/desktop-pet/README.md)。

### 下载与更新

下载 `eDesktop-1.1.0-windows-x64.zip`，完整解压后运行里面的 `eDesktop.exe`。支持 Windows 10/11 x64，请保留整个程序文件夹。

从旧版更新前，先从托盘正常退出，再替换程序文件，**保留自己的 `data` 文件夹**。设置、待办、聊天、记忆和离线语音模型现在都放在程序旁；仍使用旧 AppData 目录的用户，首次启动会自动迁移。收纳盒里的真实文件仍按原来的 Documents 路径管理。

对话和自然语言操作需要先启动 Ollama，并安装聊天模型。首次语音输入会下载约 229 MB 的离线识别模型，不需要 API Key；录音只在内存中处理，转成的文字按聊天记录保存在本地。天气查询需要网络。应用退出或桌宠关闭期间不会弹出提醒。

发布包不包含个人数据或已下载的模型。程序还没有商业代码签名，Windows 可能显示 SmartScreen 提示；请确认下载来源，并使用附带的 `.sha256` 文件核对压缩包。
